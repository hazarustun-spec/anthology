- **Connections are easy to find:** a "Connections" button now sits at the bottom of the sidebar and opens Settings › Connections. A dot next to it means no AI tool is connected yet, or one needs an update. (Before, Settings was only in the menu bar.)

### Install or update

```sh
curl -fsSL https://raw.githubusercontent.com/hazarustun-spec/anthology/main/install.sh | sh
```

Requires macOS 26 (Tahoe) or newer. Signed with Developer ID and notarized by Apple.
